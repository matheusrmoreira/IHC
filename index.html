O que é IHC?

A Interação Humano-computador é uma área de estudos sobre como os humanos podem se relacionar com os meios digitais, como os computadores, smartphones e tablets. Além disso, é uma área que busca melhorar e facilitar essa comunicação

Principais Características:

  • Usabilidade

    • Facilita a utilização do sistema para as pessoas.

  • Acessibilidade

    • Garante que o sistema seja utilizável por qualquer pessoa, independente de suas capacidades.

  • Performance

    • Buscam melhorar a velocidade e eficiência do sistema.

Relação com a Matériaa:

A IHC é uma área importante na disciplina de Desenvolvimento de Interfaces, pois estuda como as pessoas interagem com os sistemas computacionais e como essas interações podem ser melhoradas para tornar a experiência melhor.
